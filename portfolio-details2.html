Overview

Module 02 continues the equipment-training series, adding new components and refining the interaction model so a trainee can move around and inspect the equipment from any angle before operating it.

The GIF capture in the gallery is pulled directly from the working Oculus build — the actual in-headset walkthrough rather than a pre-rendered flythrough — which is how the module was validated for usability with training stakeholders.
